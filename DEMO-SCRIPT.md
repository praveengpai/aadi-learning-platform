# CIF Learning Platform — 15-minute funder demo script

The platform is CIF's; AADI (Komalikudi) is one programme on it — show both: the platform
serving many agencies, and AADI as the flagship community-run programme.

All people are fictional. Password for every demo account: `demo1234` (or click the name on the sign-in page).

## 1. The problem and the promise (1 min) — sign-in page
"One platform for every tribal hamlet, from the first letter to the first job. Works without
internet. The family owns the data. Many agencies, one hamlet, no duplication."

## 2. A child's day (3 min) — `demo.learner` (Anjali, Class 8, Pachakkudi)
- Home: big picture tiles, read-aloud button, switch to Malayalam (top right).
- **My Learning** → today's goals, streak, badges, the hamlet's group goal → open a lesson → 🔊 read aloud → practice quiz.
- **My Learning Passport** → skills earned from different agencies in one record; print / verify code.
- **Library** → her own Class 8 textbooks in Malayalam medium, books the teacher assigned with a note and due date, "continue reading" with bookmark.
- **My Learning Shelf** → everything she has finished, year by year and subject by subject; **Revise today** picks 3–5 items (low scores first); Open → then Easy / OK / Hard. Print / take home.
- **Help — I need someone** → calm screen, Childline 1098 / 112 / 181; a report goes only to the Child Protection Officer.

## 3. A young person getting job-ready (3 min) — `demo.youth` (Mani, PSC aspirant, Thenmala)
- **Exam Prep** → mock scores rising from 24% to 60%, PSC OMR-style mock test with negative marking, revision due today, application tracker with hall ticket.
- **Career pathways** → Police Constable: eligibility → exam → physical test → timeline.
- **Life Skills** → online-safety gate, city travel, rights at work, document checklist (no ID numbers stored).
- **Language Lab** → job-interview and bus-stand conversations, record and self-rate speaking.

## 4. The family decides (2 min) — `demo.guardian`
- Sees each child's progress in plain Malayalam.
- **Child's shelf** → this month in plain words (read aloud): lessons finished, revision streak, average score. **Child's books** → what the teacher assigned.
- Opens a child → **Consent** → withdraws consent for an agency → that agency instantly loses access.
  (Show it: sign in as `demo.facilitator` before and after.)

## 4b. AADI — a community-run programme on the platform (1 min)
- `demo.aadi.lead` (Komalikudi Youth Group) → **Hamlets** → Komalikudi → each programme shows
  "AADI Smart Learning Centre · sponsored by CIF": tuition 1–SSLC, PSC coaching, counselling,
  digital skills, literacy — the same services as the AADI poster.

## 5. The facilitator and the shared hamlet (3 min)
- `demo.facilitator` (Remya, CIF) → **Teaching Console**: today's sessions, one-tap attendance, at-risk learners with reasons.
- **Learners & families**: she sees only learners enrolled with CIF whose families consented; phone numbers masked without contact consent.
- `demo.coordinator` → **Hamlets** → Pachakkudi → **service map**: CIF and Vanajyothi both run tuition (shared track), timetable clashes, gaps.
  **Hamlet Coordination** board: the agencies talk to each other here.

## 6. Proof for funders and government (2 min)
- `demo.donor` → **Impact dashboard** and **Funder report** (printable): reach by hamlet, gender, track, learning gains, SDG 4/8/10 mapping — all anonymised, counts under 5 hidden.
- `demo.govt` → same, aggregate only.

## 7. Fail-safe, live (1 min) — `demo.steward`
- **Services (modules)** → switch *Exam Prep* off → sign in as youth: a calm "resting" notice, everything else works → switch it back on.
- **Sync & resilience** → verify the tamper-evident event chain; export a USB courier bundle.
- On the hub URL (if deployed): **Go offline** → register a learner → **Reconnect** → the learner appears in the cloud.
- **Feature-phone Simulator** (`demo.facilitator`) → SMS inbox and the spoken IVR menu for families without smartphones.
- **How AADI works** → the brain and the services around it.
